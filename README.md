# Water Tank Problem Visualizer

An elegant, standalone web application built to solve and visually illustrate the **Trapping Rain Water / Water Tank Problem** using Vanilla JavaScript, HTML5, and CSS3.

## 🚀 Features
- **Dynamic Calculation:** Computes total water units trapped between blocks in real-time.
- **Interactive Visualizer:** Renders an on-the-fly **SVG Shape grid view** mapping out structural walls and trapped water zones perfectly.
- **Input Validation:** Confirms all values are valid numbers greater than -1.

## 📊 Algorithmic Complexity

The computational engine handles array arrays efficiently:
- **Time Complexity:** $O(n)$ — Traverses the topology structure array array elements linearly in two quick scans.
- **Space Complexity:** $O(n)$ — Space tracking arrays map boundaries to render exact coordinates over the grid blocks smoothly.

## 🛠️ Execution & Deployment Steps

Since this project relies completely on pristine Native Frontend languages without bundle compilers or third-party overhead layers, deploying it takes seconds:

1. **Extract/Download** the files inside your project directory.
2. Locate the file named `index.html`.
3. **Double-click** `index.html` or drag it directly into any modern desktop internet browser (Chrome, Safari, Firefox, Edge).
4. Enter any custom configuration sequence comma-separated (e.g. `0,4,0,0,0,6,0,6,4,0`) and click **Compute & Visualize**.
